Method and interpretation
What this prototype actually computes
LOCAL
The API parses observed flow rows, extracts the feature vector and builds a directed host graph. With at least 12 records it fits Isolation Forest to numeric features in the uploaded batch and ranks flows relative to that batch. It does not claim to forecast future attack stages or use a pretrained threat model.
